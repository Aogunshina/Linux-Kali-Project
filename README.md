1. Linux System Information and Network Testing

Project type: Beginner Linux and networking assignment
Environment: Kali Linux

This project involved using basic Linux commands to identify system information and perform a network connectivity test.

Tasks completed:

Identified the current Linux username using whoami.

Checked the machine hostname using hostname.

Located the current working directory using pwd.

Inspected operating system and kernel information using uname -a.

Explored CPU information using lscpu.

Checked RAM usage using free -h.

Examined disk space using df -h.

Investigated system uptime using uptime.

Tested connectivity to Google using the ping command.

Interpreted the reported round-trip time and packet loss.

Explored the meaning of the -c 4 option in a ping command.

Recorded the IP address returned for google.com.

Results recorded in my assignment:

Kernel version: 7.1.5-amd64

Reported total RAM: 2.0 GiB

Reported available disk space on the main partition: 59 GiB

Average round-trip time: Approximately 175.227 ms

Packet loss: 0%

Resolved Google IP address: 172.217.76.100

These results reflect the environment and observations recorded during the assignment. Network results and DNS addresses may differ between systems and testing sessions.

Key learning outcomes:

Understanding how to retrieve basic system information from the Linux terminal.

Recognising the importance of monitoring CPU, memory, and disk resources.

Learning how to conduct a basic connectivity test.

Interpreting packet loss and latency results.

Documenting technical observations clearly and systematically.
